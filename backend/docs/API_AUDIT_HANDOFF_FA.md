## ۲۰) یک اختلاف واقعی در دیتابیس کاری — پیدا شد، تعمیر نشد

هنگام تأیید نهایی، شمارش ردیف‌های `finance_mpp_rows` در `bambo_canonical_test` با کپی
ایزوله یکی نبود. تعقیبش به یک اختلاف اثبات‌شده رسید:

| | `afe50159` | `bf456698` (نسخهٔ **فعال**) |
|---|---|---|
| `row_count` که ردیف نسخه اعلام می‌کند | ۷۸۹ | **۷۸۹** |
| ردیف‌هایی که واقعاً هست | ۷۸۹ | **۷۸۸** |
| تخصیص‌های بدون منبع | ۱۲ | **۱۱** |

ردیف غایب یکی است و مشخص است:

```
source_task_uid = 1209   source_assignment_uid = 8847   source_resource_uid = NULL
WBS 1.2 — «تحویل زمین»   units = 1   cost = 0   quantity = NULL   rate = NULL
```

یک **milestone بدون منبع** است. در همان دیتابیس، نسخهٔ قدیمی‌تر آن را دارد؛ کپی ایزوله
هم دارد — یعنی موقع گرفتن کپی موجود بوده.

**اثر روی اعداد گزارش: هیچ.** بدون منبع یعنی ردهٔ `activity_only`، بدون خط برآورد
(شمارش خطوطی که این تخصیص را نام ببرند: **صفر**)، بدون مبلغ. تنها چیزی که جابه‌جا می‌شود
شمارندهٔ وضعیت نگاشت است (`activityOnly` می‌شود ۱۱ به‌جای ۱۲، و سه حالت به ۷۸۸ جمع
می‌زنند نه ۷۸۹).

**ولی دو نکته می‌ماند:**

۱. `row_count` و واقعیت در دیتابیس کاری با هم نمی‌خوانند — و این تنها جایی است که چنین
   ناسازگاری‌ای وجود دارد.
۲. sync خودش این را «تعمیر» می‌کند، اما **شمارنده را، نه ردیف را**:

```python
if existing["row_count"] != existing["actual_row_count"]:
    # Repair metadata only; unchanged source/financial rows retain
    # their IDs and history. Older refreshes left this count stale.
    UPDATE finance_mpp_source_versions SET row_count = actual_row_count
```

یعنی اولین sync بعدی روی همان بایت‌ها، `row_count` را به ۷۸۸ می‌آورد و دفتر با فقدان
موافقت می‌کند به‌جای اینکه ردیف را برگرداند. کامنت خودِ کد علت را نام می‌برد:
«refreshهای قدیمی‌تر این شمارنده را کهنه می‌گذاشتند».

**تعمیر نشد** — دستورالعمل این کار صریحاً اجازهٔ ترمیم داده در دیتابیس کاری را نمی‌دهد و
این خواندنی بود، نه نوشتنی. راه درست بازیابی هم موجود است و بی‌خطر: یک `sync` با
`refresh=true` روی همان بایت‌های `bf456698` هر ۷۸۹ ردیف را از نو می‌سازد بدون آنکه ردیف
نسخه، ارجاع‌های snapshot یا گزارش‌های صادرشده را لمس کند (`snapshot_payload` هر گزارش
صادرشده تغذیه‌اش را در لحظهٔ صدور منجمد کرده است). **تصمیمش با شماست.**
