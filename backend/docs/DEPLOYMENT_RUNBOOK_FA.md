# دستورالعمل استقرار

**مرجع تاریخی این سند:** `backend-finance`
**نسخه Schema فعلی:** `0020`
**زمان اجرا:** Python 3.12

هیچ رمز یا DSN واقعی در این سند نیست. `<...>` را از محیط انتشار بگیرید.

> ماژول مالی یک **کتابخانه** است، نه یک سرویس. میزبان BAMBO آن را نصب می‌کند و روی
> `application.state` سیم‌کشی می‌کند. این سند مراحلی را می‌گوید که میزبان باید طی کند.

---

## ۱. کامیت تأییدشده

```bash
git fetch origin
git checkout backend-finance
git log --oneline -1        # با کامیتی که تأیید شده مقایسه کنید
git status --short          # باید تمیز باشد
```

```
□ روی کامیت تأییدشده ایستاده‌ایم
□ درخت کاری تمیز است
□ master ادغام نشده — شاخه معتبر مالی همین است
```

---

## ۲. محیط Python 3.12

```bash
python3.12 -m venv <venv-path>
<venv-path>/bin/python -V        # باید 3.12.x بدهد
```

```
□ نسخه دقیقاً 3.12 است
□ محیط ایزوله است و با محیط توسعه اشتراک ندارد
```

> نسخه هدف عمداً ثابت است. اجرای سوئیت روی نسخه دیگری «اعتبارسنجی» نیست.

---

## ۳. نصب وابستگی‌ها

```bash
<venv-path>/bin/pip install -r backend/requirements.txt
```

```
□ نسخه‌ها برای سبزشدن تست تغییر داده نشدند
□ requirements-test.txt روی Production نصب نمی‌شود
□ uvicorn فقط اگر میزبان سرور خودش را ندارد
```

`requirements.txt` فهرست چیزی است که یک **میزبان** نصب می‌کند. ابزار تست در آن نیست و یک
تست این را قفل کرده.

---

## ۴. اعتبارسنجی محیط

```
□ FINANCE_MIGRATION_DSN فقط در Shell انتشار تنظیم است — نه در محیط اجرا
□ FINANCE_DEV_DSN تنظیم نیست
□ FINANCE_CORE_DSN تنظیم نیست
□ FINANCE_ALLOW_SEED تنظیم نیست
□ APP_ENV=development تنظیم نیست
```

سه ردیف آخر اگر تنظیم شوند بی‌اثرند — میزبان Production ماژول `devhost` را import نمی‌کند و
یک تست این را تضمین می‌کند. ولی نبودشان لایه دومی است که به «کسی اشتباه نکند» تکیه ندارد.

جزئیات در `PRODUCTION_ENVIRONMENT_FA.md`.

## ۵. پشتیبان دیتابیس

**قبل از Migration، همیشه.** جزئیات در `BACKUP_RESTORE_RUNBOOK_FA.md`.

```
□ پشتیبان گرفته شد
□ با pg_restore -l بازرسی شد
□ حجم و زمان و نسخه Client ثبت شد
□ دست‌کم یک‌بار روی یک دیتابیس یک‌بارمصرف بازیابی شد
```

---

## ۶. دروازه تأیید Migration

**اینجا متوقف شوید.** خروجی دروازه ایمنی را بگیرید و به تأییدکننده نشان دهید:

```sql
SELECT current_database(), inet_server_addr(), inet_server_port(),
       version(), current_user;
```

```
□ هر پنج مقدار با آنچه انتظار می‌رود می‌خواند
□ current_user نقش Owner است، نه نقش اجرا
□ تأیید صریح انسانی گرفته شد
□ نام تأییدکننده و زمان ثبت شد
```

> **اگر این مرحله در یک اسکریپت خودکار شد، دیگر دروازه نیست.**

جزئیات در `PRODUCTION_MIGRATION_RUNBOOK_FA.md`.

## ۷. اجرای صریح Alembic

```bash
cd backend
export FINANCE_MIGRATION_DSN="<owner-dsn>"
alembic upgrade head
```

```
□ finance_alembic_version = 0020
□ ۱۵ جدول مالی موجودند
□ ۱۰ تریگر تغییرناپذیری موجودند
□ جدول عمومی alembic_version ساخته نشده
□ خروجی بایگانی شد
```

**برای بازبینی قبلی بدون اجرا:**

```bash
alembic upgrade head --sql > planned.sql
```

هر شش Revision در حالت Offline هم کار می‌کنند.

## ۸. راه‌اندازی برنامه

میزبان BAMBO ماژول را سیم‌کشی می‌کند. چهارده کلید لازم در
`CORE_HOST_WIRING_FA.md` فهرست شده‌اند.

```
□ سه Adapter امنیتی سیم‌کشی شدند
□ یازده سرویس دامنه سیم‌کشی شدند
□ نقش دیتابیسِ اجرا حق CREATE ندارد
□ برنامه بالا آمد
```

> **راه‌اندازی برنامه هیچ Migrationی اجرا نمی‌کند.** اگر Schema نباشد، پیام روشن می‌دهد و
> می‌گوید چه دستوری را باید زد. اجرای یک پروسه، رضایت به تغییر Schema نیست.


## ۱۰. معیار بازگشت

**قبل از استقرار تصمیم بگیرید که چه چیزی باعث بازگشت می‌شود، نه بعدش.**

| نشانه | اقدام |
|---|---|
| Migration خطا داد و تراکنش برگشت | ادامه ندهید. Schema دست‌نخورده است |
| Migration موفق، برنامه بالا نمی‌آید | برنامه را برگردانید. دیتابیس را دست نزنید |
| Smoke test فقط‌خواندنی رد شد | برنامه را برگردانید |
| داده اشتباه نوشته شد | برگرداندن برنامه کمکی نمی‌کند — بازیابی پشتیبان با تأیید |

**بازگشت برنامه ≠ بازگشت دیتابیس.** جزئیات در `ROLLBACK_RUNBOOK_FA.md`.

## استقرار خودکار

**در این مخزن وجود ندارد و در این فاز ساخته نشد.**

اگر بعداً ساخته شود، این‌ها هرگز نباید در آن باشند:

```
✗ alembic upgrade      ← تأیید انسانی لازم دارد
✗ alembic downgrade    ← تصمیم داده‌ای است
✗ alembic stamp        ← دیتابیس را وادار به دروغ‌گفتن درباره خودش می‌کند
✗ seed / reset         ← Production هرگز داده نمایشی نمی‌گیرد
```
