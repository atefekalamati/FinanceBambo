# استخراج خودمیزبان — نصب و راه‌اندازی

OCR تصویر و رونویسی صدا، **کاملاً روی سرور خودتان**. هیچ فایلی و هیچ متنی از سرور بیرون
نمی‌رود؛ هیچ API خارجی صدا زده نمی‌شود. یک تست این را روی کد تضمین می‌کند: هیچ‌کدام از
providerها اجازهٔ import کردن `requests`، `httpx`، `urllib`، `aiohttp`، `socket`، `openai` یا
`boto3` را ندارند.

---

## چرا این بسته جدا از ماژول مالی است

`app/finance` ماژول قابل استقرار است و عمداً هیچ پیاده‌سازی استخراجی ندارد —
`adapters/ports.py` فقط دو پروتکل تعریف می‌کند و میزبان پرشان می‌کند. `coreint/` هم دقیقاً
همین رابطه را با Core دارد، و `extraction/` خواهر آن است.

اینجا دلیل سنگین‌تری هم دارد: PaddleOCR و Whisper چند گیگابایت وابستگی یادگیری ماشین
می‌آورند. اگر داخل `app/finance` می‌رفتند، آن چند گیگابایت وارد **هر** استقرار ماژول مالی
می‌شد — حتی آنهایی که هرگز تصویری پردازش نمی‌کنند — و یک مرز پورت به یک import تبدیل می‌شد.

```
extraction/       ← اینجا نصب می‌شود، میزبان سیم‌کشی‌اش می‌کند
app/finance/      ← هیچ‌وقت از آن import نمی‌کند (تست تضمین می‌کند)
```

## نصب — حالت CPU

پیش‌فرض. برای حجم کاری معمول مالی کافی است.

```bash
cd backend
pip install -r extraction/requirements.txt
```

**ffmpeg** را جداگانه نصب کنید:

```bash
# Debian / Ubuntu
sudo apt-get install -y ffmpeg

# RHEL / Rocky
sudo dnf install -y ffmpeg

# Windows
winget install Gyan.FFmpeg
```

بررسی:
```bash
ffmpeg -version
python -c "import paddleocr, whisper, torch; print('ok')"
```

## نسخه‌های تأییدشده (اجرا و آزمون‌شده)

جدول زیر آنچه را نشان می‌دهد که روی این ماشین **واقعاً نصب شد و هر دو provider را تا
انتها اجرا کرد** — نه آنچه در `extraction/requirements.txt` پین شده است. آن فایل هدفش
سرور Linux است و پین‌هایش روی Windows با CPython 3.12 اصلاً wheel ندارند.

| بسته | نسخهٔ تأییدشده | محیط |
|---|---|---|
| Python | 3.12.10 | `backend/ai-extraction-env` |
| paddlepaddle | 3.0.0 | CPU |
| paddleocr | 3.7.0 | — |
| paddlex | 3.7.2 | وابستگی paddleocr |
| openai-whisper | 20250625 | محلی، نه API |
| torch | 2.13.0 | CPU (`cuda.is_available() == False`) |
| numpy | 2.3.5 | — |
| opencv-contrib-python | 4.10.0.84 | — |
| pillow | 12.3.0 | — |
| ffmpeg | 9.0.1 | خارج از pip، با winget |

`pip check` روی این مجموعه: `No broken requirements found`.

### دو نکته‌ای که بیشترین وقت را گرفت

**۱ — paddlepaddle 3.3.1 روی Windows/CPU کار نمی‌کند.** پیش از خواندن هر تصویری، داخل
مسیر oneDNN خودش با `ConvertPirAttribute2RuntimeAttribute not support` متوقف می‌شود.
هیچ‌کدام از `FLAGS_use_mkldnn=0`، `FLAGS_enable_pir_api=0` و `FLAGS_enable_pir_in_executor=0`
آن را دور نمی‌زنند. 3.0.0 درست کار می‌کند و در `requirements-ai.txt` سقف `<3.1` گذاشته
شده. این سقف را فقط پس از اجرای دوبارهٔ `extraction/scripts/test_ocr.py` روی همان
سکو بالا ببرید.

**۲ — `winget install Gyan.FFmpeg` مسیر ffmpeg را روی PATH نمی‌گذارد.** نصب موفق است
ولی `shutil.which("ffmpeg")` همچنان `None` برمی‌گرداند، و Whisper — که برای **هر**
قالبی، حتی WAV، به ffmpeg شل می‌زند — با `[WinError 2]` از درون مدل شکست می‌خورد؛
خطایی که مثل یک فایل صوتی خراب به نظر می‌رسد. یا مسیر زیر را به PATH اضافه کنید یا آن
را به provider بدهید:

```
%LOCALAPPDATA%\Microsoft\WinGet\Packages\Gyan.FFmpeg_*\ffmpeg-*-full_build\bin
```

```python
WhisperProvider(ffmpeg=r"C:\...\bin\ffmpeg.exe")
```

### آنچه این اجرا ثابت کرد و آنچه ثابت نکرد

**ثابت شد:** هر دو مدل بارگذاری می‌شوند، روی CPU اجرا می‌شوند، خروجی می‌دهند، و قرارداد
`ExtractionResult` را پر می‌کنند. هیچ درخواست شبکه‌ای جز دانلود یک‌بارهٔ وزن مدل‌ها انجام
نشد.

**ثابت نشد — دقت فارسی.** آزمون‌ها با فایل‌های *ساختگی* انجام شد: یک تصویر که با PIL
ساخته شده (که خط فارسی را بدون اتصال حروف می‌کشد، پس متن خروجی به‌هم‌ریخته است) و یک
صدای تُن خالص. تا وقتی یک فاکتور اسکن‌شدهٔ واقعی و یک صدای فارسی واقعی آزمایش نشود،
**نرخ خطای فارسی این خط لوله ناشناخته است.**

**یک هشدار جدی:** Whisper روی همان تُن خالص متنی توهمی («این این این…») تولید کرد و
اطمینان **0.91** گزارش داد. `avg_logprob` روی ورودی غیرگفتاری با اطمینان بالا اشتباه
می‌کند. بنابراین اطمینان Whisper هرگز نباید معیار پذیرش خودکار باشد — دقیقاً به همین
دلیل تأیید انسانی در این طراحی اجباری است. در آن اجرا parser هیچ فیلدی استخراج نکرد،
که رفتار درست بود.

## نصب — حالت GPU

فقط اگر NVIDIA با CUDA ۱۱٫۸ یا بالاتر دارید. **دو بستهٔ بالا را با نسخهٔ GPU جایگزین
کنید**، نه اینکه کنارشان نصب کنید:

```bash
pip uninstall -y paddlepaddle torch

# PaddlePaddle GPU — از index خودش
pip install paddlepaddle-gpu==2.6.2 \
  -i https://www.paddlepaddle.org.cn/packages/stable/cu118/

# PyTorch CUDA — از index خودش
pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu118
```

سپس در سیم‌کشی:
```python
PaddleOCRProvider(use_gpu=True)
WhisperProvider(model_name="medium", device="cuda")
```

بررسی:
```bash
python -c "import torch; print('cuda:', torch.cuda.is_available())"
```

## دانلود وزن مدل‌ها

هر دو کتابخانه در **نخستین استفاده** مدل را دانلود می‌کنند. روی سروری که به اینترنت وصل
نیست، این کار باید از پیش انجام شود — وگرنه اولین آپلود واقعی با خطای شبکه شکست می‌خورد.

```bash
# PaddleOCR فارسی — حدود ۲۰ مگابایت
python -c "from paddleocr import PaddleOCR; PaddleOCR(lang='fa', use_angle_cls=True)"

# Whisper — small حدود ۵۰۰ مگابایت، medium حدود ۱٫۵ گیگابایت
python -c "import whisper; whisper.load_model('small')"
```

مدل‌ها در `~/.paddleocr/` و `~/.cache/whisper/` می‌نشینند. برای سرور بی‌اینترنت، همین دو
پوشه را از یک ماشین متصل کپی کنید.

**انتخاب مدل Whisper:** `small` برای فارسی روی CPU تعادل خوبی دارد (حدود ۱۵ تا ۴۰ ثانیه
برای یک صدای ۳۰ ثانیه‌ای). `medium` دقیق‌تر است ولی روی CPU چند برابر کند. `tiny` برای
اعداد فارسی به‌اندازهٔ کافی دقیق نیست و توصیه نمی‌شود — و عدد اشتباه در فاکتور، پول است.

## سیم‌کشی در میزبان

```python
from extraction.paddle_ocr import PaddleOCRProvider
from extraction.whisper_voice import WhisperProvider

application.state.finance_extraction_service = FinanceExtractionService(
    extraction_repository, attachment_repository, storage,
    image_extractor=PaddleOCRProvider(use_gpu=False),
    voice_extractor=WhisperProvider(model_name="small"),
    invoice_service=invoice_service)
```

مدل در **نخستین استفاده** بارگذاری می‌شود، نه هنگام import — پس استقراری که هرگز تصویری
پردازش نمی‌کند، هزینه‌اش را نمی‌دهد و حتی لازم نیست بسته را نصب کند. بارگذاری پشت یک قفل
است، پس دو درخواست همزمانِ اول، دو مدل بارگذاری نمی‌کنند.

اگر بسته نصب نباشد، provider خطای روشن می‌دهد و به همین سند ارجاع می‌دهد — نه یک
`ImportError` وسط پردازش.

## پردازش پس‌زمینه

OCR و رونویسی **نباید داخل درخواست HTTP** اجرا شوند. دو مسیر وجود دارد:

```
POST /files/{fileId}/extractions          هم‌زمان — برای providerهای سریع و تست
POST /files/{fileId}/extractions/async    202 فوری، پردازش در پس‌زمینه   ← این را استفاده کنید
```

مسیر async بلافاصله وضعیت پیوست را برمی‌گرداند و کار را به `BackgroundTasks` می‌سپارد.
کلاینت با `GET /extractions?fileId=` نظر می‌کند.

**وضعیتی که مشتری دنبال می‌کند، وضعیت خودِ پیوست است**، نه یک وضعیت تازه:

```
uploaded  →  processing  →  ready       پیش‌نویس آماده است
                         →  failed      قابل تلاش دوباره
```

`finance_attachments` این چهار حالت را از قبل دارد و `start` از قبل آنها را جابه‌جا می‌کند.
ستون وضعیت دوم اضافه نشد: یک حقیقت با دو خانه، دیر یا زود دو جواب می‌دهد.

**نتیجهٔ عملی: هیچ مهاجرتی لازم نبود.** Alembic روی `0007` می‌ماند.

## آنچه provider هرگز نمی‌کند

**مقدار نمی‌سازد.** فاکتوری با مقدار و جمع کل ولی بدون قیمت واحد، مقدار و جمع را می‌دهد و
یک هشدار. تقسیم نمی‌کند — عددی که کسی ننوشته، برای بازبین از عددی که خوانده شده قابل
تشخیص نیست.

**بین دو خوانش انتخاب نمی‌کند.** دو جمع کل یعنی هیچ‌کدام قطعی نیست؛ اطمینان پایین می‌آید و
هشدار ثبت می‌شود.

**ارز را تبدیل نمی‌کند.** عددی کنار «ریال» و عددی کنار «تومان» ده برابر فرق دارند. واحد
همان‌طور که خوانده شده گزارش می‌شود.

**خط کم‌اطمینان را دور نمی‌ریزد.** حذفش بازبین را با فرمی خالی رها می‌کرد که نمی‌گوید چیزی
جا افتاده. خط می‌ماند و علامت‌دار می‌شود.

**فاکتور نمی‌سازد.** تنها راه رسیدن به فاکتور، `POST /extractions/{id}/confirm` است که تأیید
صریح هر فیلد را می‌خواهد.

## عیب‌یابی

**`paddleocr is not installed`** — بستهٔ requirements نصب نشده، یا در virtualenv دیگری است.

**`ffmpeg is not on PATH`** — با پکیج‌منیجر سیستم نصب کنید. pip نمی‌تواند.

**`Whisper failed to load small`** — وزن مدل دانلود نشده و سرور به اینترنت دسترسی ندارد.
`~/.cache/whisper/` را کپی کنید.

**متن خوانده می‌شود ولی هیچ فیلدی استخراج نمی‌شود** — متن خام را در پیش‌نویس ببینید. اگر
درست خوانده شده ولی قالب فاکتور ناآشناست، این مورد انتظار است: parser فقط الگوهایی را که
می‌شناسد گزارش می‌کند و بقیه را به بازبین می‌سپارد.

**اعداد فارسی اشتباه خوانده می‌شوند** — روی مدل `tiny` رایج است. `small` یا بالاتر.
