## ۱۰. نامعلوم‌های تأییدشده

این‌ها **حدس زده نمی‌شوند**:

1. واحدِ پایهٔ قیمت برای شش دسته از هفت دسته (به‌جز میلگرد).
2. آدرس اینترنتی منبع — ستونی برای آن وجود ندارد.
3. زمان مشاهدهٔ واقعیِ تأمین‌کننده — برگه فقط «تاریخ آپدیت ورک فلو» دارد.
4. وزن هر عدد آجر برای ۹۴ ردیف، و وزن ناودانی برای ۳۸ ردیف.
5. اینکه آیا قیمت شامل مالیات یا هزینهٔ حمل هست یا نه.

هرجا یکی از این‌ها برای یک محاسبه لازم باشد، نتیجه `unresolved` اعلام می‌شود — نه صفر.
