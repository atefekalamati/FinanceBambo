# Test tooling only. Kept apart from requirements.txt because the finance module is a
# library: what it ships to a deployed host is the runtime list, and nothing here belongs
# there.
#
# Without this file a fresh clone cannot run the suite. The tests were passing only
# because pytest and httpx happened to be installed globally on one machine, so `python -m
# pytest` worked outside a virtual environment and failed inside one.
#
#   python -m pip install -r backend/requirements.txt -r backend/requirements-test.txt
#
# httpx is not imported by any test directly. starlette's TestClient needs it, and every
# API-level test goes through TestClient.
pytest==9.1.1
httpx==0.28.1

# Same psycopg the runtime pins, plus the bundled libpq wheel. requirements.txt keeps the
# bare package on purpose: a deployed host is expected to provide its own libpq, and that
# choice is not ours to make here. A developer machine usually has no libpq at all, so
# without this every test that imports a repository fails to collect with
# "no pq wrapper available" -- which is what a fresh virtual environment does today.
psycopg[binary]==3.3.4

# The MPXJ reader test parses the checked-in reference schedule on a real JVM, and that
# file says in as many words that a machine without mpxj FAILS rather than skips: a suite
# that quietly stops parsing real .mpp files has lost the coverage it exists for. So the
# parser belongs here, where CI installs it, and not only in a developer's private
# virtual environment -- without it those eleven tests ERROR and the backend job is red,
# which is what it had been on every run.
#
# jpype1 is pinned separately because mpxj imports it without declaring it as a
# dependency: installing mpxj alone gets as far as the first parse and then raises
# ModuleNotFoundError.
#
# A full JRE is the other half of this and comes from the environment, read as
# MPP_JAVA_HOME or JAVA_HOME; the workflow installs Temurin 17. A jlink'd minimal runtime
# is not enough -- MPXJ fails inside its charset initialiser. Verified together:
# mpxj 16.7.0, jpype1 1.7.1, Temurin 17.0.20.1+1, CPython 3.12.
mpxj==16.7.0
jpype1==1.7.1
