## ۳. قرارداد API

`contracts/openapi.json` از خودِ router تولید می‌شود، نه دستی نوشته شده. **۵۱ مسیر.**

پیشوند همهٔ مسیرها:

```
/api/projects/{projectId}/finance/...
```

### چند نکته که در خواندن قرارداد به کار می‌آید

**شمارهٔ فاکتور را سرویس تعیین می‌کند.** در بدنهٔ ساخت فاکتور فیلد `invoiceNumber` **وجود
ندارد** و فرستادنش پاسخ ۴۲۲ می‌گیرد. پاسخ هر فاکتور دو چیز دارد:
`invoiceSeq` (عدد صحیح، یکتا در هر پروژه) و `invoiceNumber` (شکل نمایشی).
فاکتورهایی که پیش از این قابلیت شماره گرفته‌اند، **همان شمارهٔ صادرشدهٔ خود را نگه می‌دارند**.

**فهرست‌های صفحه‌بندی‌شده** یک پاکت مشترک دارند:
`{ items, page, pageSize, totalItems, totalPages }` — با پیش‌فرض ۵۰ و سقف ۲۰۰ ردیف.
این پاکت روی `/invoices`، `/price-history`، `/unit-conversions`، `/audit-events` و
`/activities` یکسان است.

**مبالغ همیشه رشتهٔ عدد صحیح ریال‌اند**، نه عدد اعشاری. این عمدی است: مبلغ ریالی از محدودهٔ
دقیق `Number` جاوااسکریپت فراتر می‌رود و تبدیلش به float، ریال گم می‌کند.

**`null` یعنی «قابل محاسبه نیست»، نه صفر.** هر جا سرویس نتوانسته مقداری را اثبات کند،
`null` می‌فرستد و رابط کاربری آن را «—» نشان می‌دهد. صفر فقط وقتی می‌آید که واقعاً صفر
اندازه‌گیری شده باشد.

### خطاها

همهٔ خطاها یک شکل دارند:

```json
{"error": {"code": "...", "message": "...", "requestId": "req-...", "details": [...]}}
```

| وضعیت | معنی |
|---|---|
| ۴۰۱ | نشست معتبر نیست یا منقضی شده — رابط، کاربر را به صفحهٔ ورود می‌برد |
| ۴۰۳ | نشست معتبر است ولی مجوز لازم را ندارد |
| ۴۲۲ | بدنهٔ درخواست معتبر نیست (فیلد اضافه، تاریخ ناموجود، مقدار نادرست) |
| ۴۰۹ | تعارض: نسخهٔ کهنه، فاکتور تکراری، تأیید هم‌زمان |

۴۰۱ و ۴۰۳ عمداً از هم جدا شده‌اند: اولی یعنی «وارد شوید»، دومی یعنی «دسترسی ندارید».

cd backend && python scripts/export_openapi.py --check
